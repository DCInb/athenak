# Laser-irradiated solid target: radiation and Biermann battery

This directory is a self-contained AthenaK benchmark for a finite-radius laser incident
on a smooth CH-like solid/corona interface. The laser heats the electron component by
inverse bremsstrahlung, implicit Spitzer conduction redistributes that heat with a
saturated-flux limiter, thermal multigroup radiation exchanges energy with those
electrons, and the resulting nonparallel electron-density and electron-pressure gradients
generate an out-of-plane Biermann field.

The initial target has constant temperature, so `grad(p_e)` is parallel to `grad(n_e)` and
the continuum Biermann source starts at zero. Gaussian laser heating creates the required
transverse pressure gradient. In this 2D meridional plane, the toroidal field expected
around a laser spot appears as an antisymmetric pair of positive and negative `B3`.

## What the benchmark tests

The four cases generated by `run_benchmark.py` isolate the communication paths:

| Case | Purpose |
| --- | --- |
| `coupled_gpu1` | Full laser → electron → radiation and Biermann evolution. |
| `coupled_gpu2` | Same physics across two MPI ranks; rays must transfer between ranks. |
| `no_radiation_gpu1` | Keeps FLD transport but disables matter-radiation source exchange. |
| `no_biermann_gpu1` | Keeps identical heating/radiation but sets the Biermann coefficient to zero. |

The custom history output records deposited laser energy, instantaneous deposited power,
ion/electron/radiation energies, total matter-plus-radiation energy, integrated `|B3|`,
magnetic energy, a resolved crossed-gradient Biermann source estimate, and energy
centroids. These diagnostics test the actual coupling chain rather than only checking that
each module ran.

AthenaK's relevant update order is:

```text
MHD flux/update, including radiation FLD and Biermann fluxes
  -> laser ray initialization and MPI block map refresh
  -> ray tracing, reflection, inverse-bremsstrahlung deposition
  -> identical source increment to total material energy and electron energy
  -> MHD boundary/CT/primitive update
  -> end-of-step implicit electron conduction
  -> ion/electron and electron/radiation source exchange
```

Thus the laser and thermal-radiation modules communicate through the conservative electron
energy component. The ray tracer communicates geometrically through its global leaf-block
map and, for the two-rank case, through nonblocking ray packets.

## Run

From the repository root:

```bash
python3 laser-target/run_benchmark.py --build --clean
/home/mengqi/.venvs/athenak-vis/bin/python laser-target/analyze_benchmark.py
```

GPU IDs default to `ATHENAK_TEST_GPUS`, or `2,3,4,5` when that variable is unset. Override
them explicitly when needed:

```bash
python3 laser-target/run_benchmark.py --build --clean --gpus 0,1
```

The runner uses the local AthenaK build/run helper and compiles the custom problem through
`-DPROBLEM=../../laser-target/laser_target`. This path keeps the problem generator and all
case-specific files under this directory without modifying `src/pgen/`.

Generated results are written to `runs/`, `logs/`, `plots/`, `results.csv`, `results.json`,
and `diagnostics.md`.

## Pass criteria

The analyzer requires:

- every illuminated ray trace to conserve launched power to `1e-10`, with reflected power
  explicitly accounted as deposited, escaped, or remaining;
- integrated matter-plus-radiation energy gain to agree with cumulative laser deposition
  within 5 percent (the tolerance permits short-time outflow and finite-volume errors);
- a positive radiation-energy excess relative to the uncoupled radiation control;
- nonzero Biermann source and `|B3|`, an odd-`B3` topology correlation above 0.25 and a peak in the critical layer, and a
  negligible field in the zero-coefficient control;
- nonzero off-rank ray transfers and numerical agreement between the one- and two-rank
  coupled outputs.

## Physical scale and limitations

The optical calculation uses a 351 nm wavelength, fully ionized CH-like electron number
per gram, a 100 micrometre length unit, inverse-bremsstrahlung absorption, and critical
surface reflection. The fast regression beam is 2 TW so it can run cheaply; it is not an
attempt to reproduce one particular experimental shot.

Paper comparison is therefore topology- and communication-based. An absolute field
benchmark requires a consistently dimensionalized Biermann coefficient, material EOS,
ionization, tabulated multigroup opacity, magnetized (anisotropic) conduction/Nernst
physics, and an experiment-specific pulse and target. The current conduction model is
isotropic and uses the FLASH SpitzerHighZ form with time-lagged coefficients. AthenaK's
thermal-radiation model also omits radiation pressure and momentum feedback. See
[SOURCES.md](SOURCES.md) for the papers and the exact quantities used from each one.


Unit-consistency note (2026-07 audit): the deck's `arad`, `c_light`,
`biermann_coefficient`, `power_scale_cgs`, and `electron_heat_capacity_fraction`
are *not* mutually consistent for any single physical scenario (e.g. the labeled
"2 TW" beam is ~6.7 GW under the deck's own optics scales) — by design, since this
benchmark validates coupling topology, not amplitudes. To build a dimensionally
consistent laser+radiation+Biermann run, follow the recipe in
`docs/UNITS_2T_LASER.md`, which uses this deck as its worked example.
